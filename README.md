# BAYAN X

### Evidence-Driven AI Data Incident Investigator

BAYAN X is an AI engineering prototype for secure, explainable, and auditable data-quality incident investigation.

It combines structured incident extraction, model routing, deterministic risk scoring, evidence-based root-cause analysis, security guardrails, controlled tool execution, caching, and audit logging.
